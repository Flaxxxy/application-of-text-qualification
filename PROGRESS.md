## Phase 1 — Text data (2026-10-13)

**Done**
- Downloaded all 5 text sources (Amazon 2023 chunk download got retries after one timeout).
- `src/data_text.py` (loaders → labels → clean → dedupe → balance → split), `src/preprocess_text.py` (light + classical cleaning), `src/eda.py`, `src/plots.py` (shared style + validated class colours).
- `scripts/make_notebooks.py` generates `notebooks/01_text_data.ipynb`, which is executed with outputs saved.
- Tests: `tests/test_text_data.py`, 23 passing.

**Key numbers**
- Raw 810,063 → 641,525 after cleaning (122,581 under 3 words, 13,561 ambiguous texts with different labels, 32,297 duplicates).
- Balanced 45,000 (15,000 per class) → train 31,499 / val 6,750 / test 6,751.
- External test (Customer Feedback): 75 after dedup (42 positive, 33 negative, no neutral).

**Findings / decisions**
- **Label leak 1:** Flipkart `Review` column is generated by Flipkart from the star rating (e.g. "terrific" = 5 stars in 99% of rows). Dropped; only `Summary` (customer text) used.
- **Label leak 2:** Amazon automatic titles "Five Stars" etc. (~11% of Amazon 2023). Title dropped, body kept.
- Balancing: equal share per source per class, plus a cap inside each source (no class > 3× smallest) so "memory card text = positive" can't become a shortcut. Lecturer set shrinks to 892 rows (all its negatives/neutrals kept).
- Customer Feedback: broken CSV (rows double-quoted), mostly non-retail (music, films, restaurants), no neutral → evaluate on positive vs negative only.
- Environment: `rrf` was picking up packages from `~/.local`; fixed with `PYTHONNOUSERSITE=1` on the env. pandas 3.0 in use.
- Distinctive-words chart uses document frequency (one long review said "SP3" 72 times and topped the positive list otherwise).

**Numbers**
- Packages: 981 → 948 (33 copies, 2 conflicting-label groups), train/val/test 662/94/192 (damaged 437, intact 511).
- Produce: 13,599 → 2,227 (11,372 copies = 84%), 1,558/222/447 (fresh 930, rotten 1,297; apple 750, banana 879, orange 598).
- 0 unreadable files; 0 val/test copies of train images after the split.
- Processed size: 13 MB packages, 30 MB produce.

**Findings / decisions**
- Fruit zip contains the dataset twice (`dataset/` and `dataset/dataset/`); only the top copy is indexed.
- Copy detection: perceptual hash (8 orientations) failed: rotated copies at distance 6–12 overlap with different fruits; Kaggle renders of different boxes (even damaged vs intact) are 2–6 bits apart. CLIP over-merged (one group of 8k "bananas on white"). **SSCD** (`sscd_disc_mixup`, MIT) at similarity ≥ 0.65 with leader clustering (no copy-of-copy chains) separates copies well (checked visually at 0.60–0.80). Kaggle renders: threshold 0.99 (SSCD scores all renders >0.9; at 0.98 half of matches have different labels). Fingerprints cached in `data/interim/sscd_cache.npz`.
- Roboflow packages bias: intact = mostly product/medicine boxes on studio backgrounds, damaged = mostly brown cardboard; some label noise; stock-photo watermarks. Kaggle packages are synthetic renders.

**Decided (Denis, 2026-10-13):** BoxCondition ADDED as `packages_boxcondition`; website text model = fine-tuned DistilBERT (ONNX int8, measured in Phase 5, fallback TF-IDF + LR).
Packages after adding it: 4,953 raw → 2,195 unique (BoxCondition 650 damaged / 649 intact, Kaggle 400, Roboflow 496), train/val/test 1,535/218/442.
