## Phase 1 — Text data (2026-10-13)

**Done**
- Downloaded all 5 text sources (Amazon 2023 chunk download got retries after one timeout).
- `src/data_text.py` (loaders → labels → clean → dedupe → balance → split), `src/preprocess_text.py` (light + classical cleaning), `src/eda.py`, `src/plots.py` (shared style + validated class colours).
- `scripts/make_notebooks.py` generates `notebooks/01_text_data.ipynb`, which is executed with outputs saved.
- Tests: `tests/test_text_data.py`, 23 passing.

**Key numbers**
- Raw 810,063 → 641,525 after cleaning (122,581 under 3 words, 13,561 ambiguous texts with different labels, 32,297 duplicates).
- Balanced 45,000 (15,000 per class) → train 31,499 / val 6,750 / test 6,750.
- External test (Customer Feedback): 75 after dedup (42 positive, 33 negative, no neutral).

**Findings / decisions**
- **Label leak 1:** Flipkart `Review` column is generated by Flipkart from the star rating (e.g. "terrific" = 5 stars in 99% of rows). Dropped; only `Summary` (customer text) used.
- **Label leak 2:** Amazon automatic titles "Five Stars" etc. (~11% of Amazon 2023). Title dropped, body kept.
- Balancing: equal share per source per class, plus a cap inside each source (no class > 3× smallest) so "memory card text = positive" can't become a shortcut. Lecturer set shrinks to 892 rows (all its negatives/neutrals kept).
- Customer Feedback: broken CSV (rows double-quoted), mostly non-retail (music, films, restaurants), no neutral → evaluate on positive vs negative only.
- Environment: `rrf` was picking up packages from `~/.local`; fixed with `PYTHONNOUSERSITE=1` on the env. pandas 3.0 in use.
- Distinctive-words chart uses document frequency (one long review said "SP3" 72 times and topped the positive list otherwise).
